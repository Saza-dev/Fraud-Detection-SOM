# Fraud Detection on Credit Card Applications using Self-Organizing Maps 🧠💳

This beginner-friendly project uses Self-Organizing Maps (SOMs) to detect potential fraud in credit card applications. It is a simple and visual introduction to anomaly detection using unsupervised deep learning.

## 🔍 What is it about?

The project uses a dataset of credit card applications and applies an SOM to identify unusual patterns or anomalies. These anomalies may indicate fraudulent activity. The Self-Organizing Map clusters the data and highlights regions in the grid where suspicious applications are likely to appear.

## 🚀 Features

- Uses a Self-Organizing Map for anomaly detection
- Visualizes high-dimensional data on a 2D grid
- Detects potentially fraudulent applications without labeled data
